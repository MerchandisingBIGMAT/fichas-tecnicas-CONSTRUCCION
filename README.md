# Fichas técnicas CONSTRUCCIÓN

Generador de fichas técnicas de producto en PDF (BigMat) a partir de un Excel.

## Uso
1. Abre `index.html` (o la página publicada con GitHub Pages).
2. Importa la BBDD en Excel y la carpeta de imágenes y logos.
3. Elige el tamaño (A4 o A5) y descarga:
   - **Descargar PDF de esta ficha**: la ficha que estás viendo.
   - **Descargar un PDF por ficha**: todas las fichas, una a una, cada PDF con su código LN de 8 dígitos como nombre.

## Archivos
- `index.html`: la aplicación completa en un solo archivo.
